The goal is to make this a simple, personal blog engine that I could use to just write down my thoughts and share them with others. I am familiar with markdown, so I would like to create/edit my posts using that as an editor. I would like to be able to see a realtime preview of the rendered markdown, though, as well. The display url for each post should be in the format of /posts/{yyyy}/{mm}/{dd}/slug and if a user navigates to just /posts/{yyyy} or /posts/{yyyy}/{mm} it should show a list of the posts from that year or year and month. navigating to just /posts shows a page listing of posts that would display the title, date of post, and a short description of the post (posts should be ordered in descending order). A post should be able to have 0 to many tags on it and tags should not be able to be duplicated (don't allow me to have a C# and c# tag but tags should be freeform and then saved off once used - a lot like how Azure DevOps allows someone to tag work items in their system). A post should be hidden as a draft until I explictly publish it as well. People reading the posts should be able to leave comments, but the comments should allow for moderation so that the author can determine if certain comments need to be blocked/deleted.

Posts that get created will sometimes need photos, so there needs to be some type of media library built into this application as well. I should be able to easily add/edit/delete photos from the gallery. Editing will just consist of rotating, resizing, and/or cropping (where the cropping editor should be a visual drag of what the image will look like). The media items should also be easy to add to posts from within the markdown editor when adding/editing post content.
